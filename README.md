# Udemy Homepage Clone

A clean, responsive front-end replica of the Udemy homepage landing page. This project demonstrates modern UI layout techniques using HTML5 and CSS Flexbox without relying on external CSS frameworks.

---

## 🌟 Features

- **Responsive Header & Navigation:** Includes logo, dynamic search bar layout, and user quick links.
- **Category Bar:** Modern pill-style navigation for quick course filtering options.
- **Course Showcase Cards:** Flexbox-powered course cards featuring ratings, thumbnails, instructor names, and pricing.
- **Topic Recommendations:** Grid/Flexbox button array for suggested tech stack topics.
- **Footer Section:** Multi-column link structure with brand branding.

---

## 🛠️ Built With

* **HTML5** – Semantic markup structure
* **CSS3** – Custom styling & CSS Flexbox for layout responsiveness
